# Récapitulatif du Projet : Portfolio Personnel

**Auteur :** Gwladys

**Lien du site :** <https://gwladys-debug.github.io/portefolio/>

**Métier / Profil :** Développeuse Web & Web Mobile (DWWM)

## 1. Vue d'ensemble & Objectifs

Ce portfolio constitue votre vitrine professionnelle. Il met en valeur votre profil polyvalent en faisant le lien entre vos compétences organisationnelles/administratives et votre expertise en développement web. Il permet aux recruteurs et clients de consulter vos réalisations, votre CV et vos liens professionnels (GitHub, LinkedIn).

## 2. Projets Principaux Présentés

### 🎬 Pix'nMotion

- **Description :** Plateforme web sur-mesure pour une entreprise de production audiovisuelle.

- **Fonctionnalités clés :** Showcase vidéo, galerie interactive de projets, demandes de devis personnalisées.

- **Stack technique :** React, Next.js (App Router), TypeScript, Tailwind CSS, Neon PostgreSQL, Cloudinary, Resend, Vercel.

### 🪵 Tropik Bwa

- **Description :** Application web dédiée à l'agencement et à la menuiserie sur-mesure.

- **Focus :** Valorisation du savoir-faire artisanal, catalogue de réalisations et prise de contact.

### 🌙 Somnia (anciennement Noctura)

- **Description :** Application d'accompagnement et d'aide au sommeil.

- **Focus :** UX/UI soignée, suivi personnalisé et fonctionnalités d'aide à la relaxation.

### 📚 Projets de Formation & Certification

- **DWWM Blog :** Plateforme de blogging développée lors du parcours de formation.

- **Resto Besto :** Site vitrine/gestion pour la restauration.

- **ECF2 Journal de Stage :** Bilan et synthèse de l'expérience professionnelle en entreprise.

## 3. Architecture & Tech Stack Globale

| **Domaines** | **Technologies / Outils** |
| **Front-End** | React, Next.js (App Router), TypeScript, HTML5, CSS3, Tailwind CSS |
| **Back-End & BDD** | Next.js API Routes, Neon PostgreSQL, Prisma / ORM |
| **Services Tiers** | Cloudinary (médias/images), Resend (emails & devis) |
| **Hébergement & Déploiement** | Vercel (Applications fullstack), GitHub Pages (Portfolio) |
| **Versioning & Outils** | Git, GitHub, VS Code |

## 4. Synthèse des Points Forts du Portfolio

1. **Double compétence valorisée :** Mise en avant explicite de l'alliance entre rigueur administrative et développement web.

2. **Exemples applicatifs complets :** Présentation de projets réels couvrant du Fullstack Next.js jusqu'à l'intégration front-end responsive.

3. **Services cloud modernes :** Intégration de solutions serverless et cloud performantes (Neon DB, Cloudinary, Resend).
